# SIDEY Windows v1.3.0

2026년 9월 14일

새 캐릭터와 투척물을 지원하고 테마 선택과 상점 사용성을 개선했습니다.

## 설치

Windows 11 25H2 이상 x64 PC에서 첨부된 `SIDEY-Windows-x64-v1.3.0-Setup.exe`를 실행하세요. 기존 버전 위에 설치하면 설정과 로그인 정보가 유지됩니다.

1.3.0 설치 중 오류가 발생했다면 이 릴리스의 설치 파일을 다시 내려받아 실행하세요.

v1.0.3·v1.0.4는 앱 안에서 업데이트 파일을 내려받지 못하므로 최신 설치 파일을 직접 받아 설치해야 합니다.

## 변경 사항

- 아기 수달·아기 돼지·나무와 눈송이·야구공·왁뿌볼·두쫀쿠, 캐릭터별 애착 물건 7종을 미리 보고 보유 상품을 사용할 수 있습니다.
- 캐릭터와 별도로 판매되는 애착 물건의 가격·보유 상태를 함께 확인하며, 투척물을 장착하지 않으면 기본 말랑공을 사용합니다.
- 내 나무를 한 번 우클릭하면 걷기를 멈추거나 다시 시작하며, `더블 우클릭 후 던지기`를 켜면 내 캐릭터를 두 번 우클릭한 뒤 친구를 클릭해 물건을 던집니다.
- 밝게·어둡게·Windows 기본값 테마를 선택하고 입력창과 최근 기록에도 적용할 수 있습니다.
- 상점의 긴 상품명·미리보기·스크롤과 로딩 표시를 개선했습니다.
- 트레이에서 업데이트를 확인하면 설정창을 열지 않고 Windows 알림으로 결과를 받습니다.
- 정보 화면에서 문제 확인에 필요한 진단 데이터를 내보낼 수 있습니다.
- 설치 오류 안내와 내부 안정성을 개선했습니다.
- 앱 안에서 업데이트할 때 설치가 중단되던 문제를 수정했습니다.

## 알아두세요

- Windows 앱에서는 구매를 지원하지 않으며, 유료 상품은 연결한 계정의 보유 내역을 확인한 뒤 사용할 수 있습니다.
- Windows 버전은 공인 코드 서명 전 정식판으로, SmartScreen 경고가 표시되거나 일부 보안 설정에서 실행이 차단될 수 있습니다.
