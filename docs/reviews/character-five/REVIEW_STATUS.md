- 물건 기획 선택: 시바 테니스공, 오리 물방울, 똥 휴지 뭉치, 떡볶이 어묵꼬치.
- 쿼카: 잎사귀와 풀 뭉치를 둘 다 예시 페이지에 표시. 하나의 물건 선택은 아직 없음.
- 승인 대기: 실제 기본 자세 5종, 전체 90프레임, 움직임·idle 타이밍, 물건 최종 그림·회전·충돌, 음원·합성.

## 검증 근거

- 원본 PNG 10개를 최초 자산 커밋과 PR HEAD 양쪽에서 대조했다. 원작 Author·AuthorDate·공동 작성자를 보존한 이관 커밋은 `a7e0af2406ce8b1ee0b2aeae653f66c4ed35087a`다.
- 독립 검사에서 원본 90프레임의 발 기준선 유지·hard alpha, 발 단절 20프레임, 경계 접촉 22프레임과 던지기 중복을 확인했다. 접촉을 실제 잘림으로 단정하지 않았다.
- 24×24 후보의 원작 팔레트 보존·발 기준선·변경 좌표·해시를 대조했다. 변경 픽셀 수는 시바 56, 오리 16, 똥 0, 떡볶이 0, 쿼카 34다. 0개 변경은 원본 기본 자세 유지 선택을 위한 명시적 비교안이다.
- `verify_package.py`는 현재 자료의 무결성을 검사한다. `--require-approved`는 승인이 없거나 최종 산출물이 빠진 현재 상태에서 실패한다. 승인 이후 해시 변경·다른 후보 선택·선행 승인 누락 등을 회귀 검사한다.
- 연결된 Browser가 없어 로컬 headless Chromium으로 검토했다. 90프레임 선택, 재생·정지, 반전·실루엣, 세 배경·네 가장자리·네 정수 배율, 동작 종료 후 기본 자세 복귀와 390px 레이아웃을 확인했다. 정확한 브라우저·소스 해시·항목은 `browser-validation.json`에 기록했다. 문서 숨김은 합성 이벤트로 검사했으며 OS 최소화와 실제 앱 검증으로 보고하지 않는다.
- 기존 활성 자산 검사 및 workflow 기본 검사에서 현재 캐릭터 12종·투척물 15종·말풍선 3종과 배포 mirror·릴리스 메타데이터를 확인했다. 검토 패키지 때문에 활성 목록을 변경하거나 검사기를 완화하지 않았다.
