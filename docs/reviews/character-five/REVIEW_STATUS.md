# 현재 검토 상태

2026-09-13 · 기본 main `1480561350491bd7377b3cb925e453396b0fc961`에서 분리한 `shared/character-five-review`의 중간 검토 기록이다. 전체 자산 패키지 완성·출시·앱 실행 성공 기록이 아니다.

## 사용자 선택

현재 유효한 파일 해시와 실제 응답은 `approvals.json`에서 관리한다. 이전 기록은 `history/approvals-v1.json`부터 `history/approvals-v3.json`까지 보존한다.

- 채택 대상 5종과 서면 계약 완료 확인은 유지한다.
- 시바·오리·똥·떡볶이의 기본 외형은 원본 유지 승인이다. 발 단절과 던지기 중복 보정은 허용되었고, 보정한 전체 동작은 별도 검토 대상이다.
- 쿼카는 동물의 정체성만 유지하고 새로 해석한다. 새 24×24 기본 자세는 외형 승인 대기다. 사용자의 후속 요청에 따라 승인 전에 전체 18동작 후보도 제작했다.
- 물건 기획은 시바 테니스공, 오리 기존 삑삑 오리, 똥 휴지 뭉치, 떡볶이 어묵꼬치, 쿼카 잎사귀로 확정했다. 물방울과 풀 뭉치는 채택하지 않는다.
- 선택 콘셉트 승인과 새 물건 60프레임의 최종 그림·회전·충돌 승인은 구분한다. 오리는 기존 상품의 그림·승인 음원 재사용이 확정되었다. 나머지 물건 프레임·음원과 전체 합성·idle 타이밍은 승인 대기다. 캐릭터·물건별 고유 설명 10개는 사용자 요청에 따라 짧은 농담을 넣은 문구로 다시 작성했으며 승인 대기다.

## 검증 근거

- 원본 PNG 10개를 최초 자산 커밋과 PR HEAD 양쪽에서 대조했다. 원작 Author·AuthorDate·공동 작성자를 보존한 이관 커밋은 `a7e0af2406ce8b1ee0b2aeae653f66c4ed35087a`다. GitHub API의 해당 커밋 작성자 계정은 `jungjiyu`로 확인되었으며 main 반영은 아직이다.
- 원본 90프레임의 hard alpha·발 기준선, 발 단절 20프레임, 경계 접촉 22프레임과 던지기 중복을 기록했다. 원본 자료는 수정하지 않았다.
- 원본 외형 유지 4종의 72프레임 중 18장만 보정했다. 발 단절 16장과 던지기 2장, 총 133픽셀 변경이다. 기본 0번 동일성, 원작 팔레트, hard alpha, y=20 발 기준선, 몸·발 연결과 던지기 0–3 구분을 검사했다. 경계 접촉만으로 원작 실루엣을 축소하지 않았다.
- 새 쿼카 v3는 기존 SIDEY 캐릭터의 비율과 픽셀 표현을 참고해 코드로 다시 그렸다. 작은 눈과 파란 목도리를 적용했고 생성 콘셉트와 실제 24×24 후보를 구분한다. 기본 미리보기는 새 쿼카 18동작을 포함한 최신 후보 90프레임을 사용하며 원본은 명시적으로 비교할 때만 표시한다.
- 물건 5종·60프레임은 결정적 재생성, hard alpha·크기·해시·회전 중심·프레임 중복을 검사했다. 목욕 오리는 기존 승인 물건 `throwable_squeaky_duck`의 시트를 그대로 복사했으며 출처와 해시를 기록했다. 신규 상품 중복 등록은 하지 않았다.
- `verify_package.py`와 회귀 테스트가 자료 무결성을 검사한다. 현재 파일 64개가 등록되어 있으며 필수 자산 누락은 없다. 사용자 승인 대기 30단계가 있어 `--require-approved`는 실패해야 한다. 설명 승인 추가 5단계가 캐릭터·물건 설명 10개를 다룬다.
- 로컬 headless Chromium으로 최신 5종 걷기·상태 선택, 물건별 소리 버튼 11개와 단일 재생, 회전·충돌·고정 조합 투척/피격, 중지/전환/숨김 취소, 원본 비교, 상세 90프레임과 390px 레이아웃을 확인했다. 실제 완료 결과와 소스 해시는 `browser-validation.json`이 근거다. 문서 숨김은 합성 이벤트로 검사하며 실제 앱 실행 검증이 아니다.
- 활성 자산 목록이나 플랫폼 배포 사본·검사기를 변경하지 않는다. 검토 자료는 `docs/reviews/character-five/`에서만 로컬로 제공한다.

- 현재 음원 후보는 11개다. 테니스공·어묵꼬치는 기존 저장된 CC0 실제 팝·찰진 타격 녹음에서 각 3개를 만들었고, 오리는 기존 승인 꽥 소리를 바이트 그대로 재사용한다. 휴지·잎사귀는 각 2개의 합성 후보를 유지한다. 새 녹음 파생 후보는 기존 오리 음원과 RMS 차이 최대 1.58dB이며 48 kHz·16-bit PCM·mono, 클리핑 없음과 소스·이용 조건·해시를 검사했다. 원본 CC0 권리를 제한하지 않는다. 자연스러움과 귀여움은 사용자 청취 대상이며 자동 검사로 승인하지 않는다.
