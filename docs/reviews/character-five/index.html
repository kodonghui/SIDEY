원본과 최신 후보

4종은 원본 외형 유지, 쿼카는 새 갈색 체형으로 재제작한 후보입니다.

프레임 검사

기본 선택은 새 쿼카를 포함한 최신 후보 90프레임입니다. 원본은 직접 선택했을 때만 표시합니다.

프레임 검사 조작

걷기 0.16초/장 · 22pt/s · 30 FPS. 24px 원본이 앱에서 48pt이므로 2× 배율을 기준으로 속도를 환산합니다. 발 기준선은 위에서 y=21 경계입니다. 졸기 0.8초/장, 잠 1.2초/장, 던지기 0.4초·방출 0.2초, 피격 0.44초입니다. 브라우저 미리보기는 실제 앱 실행 검증과 구분합니다.
