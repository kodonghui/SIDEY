다섯 친구, 외형부터 확인하기

정지유 (@jungjiyu)의 원작과 수정 후보를 비교하는 로컬 검토 자료입니다. 현재 단계는 4종 동작 수정본·쿼카 새 외형·물건 5종 검토입니다.

시바견·오리·똥·떡볶이는 원본 외형을 유지하기로 승인되었습니다. 쿼카는 목도리 없는 따뜻한 갈색 체형으로 새로 제안합니다. 물건 5종의 기획은 선택됐고, 수정 동작·물건 프레임·음원 승인은 별도입니다. 페이지 조작은 승인을 기록하지 않습니다.

외형 비교움직임 비교캐릭터 프레임물건 60프레임

1. 실제 외형 픽셀 비교 원본 4종 승인 · 쿼카 대기

현재 검토하는 24×24 PNG와 실제 원본·각 실루엣을 정수 6배로 표시합니다. 시바견·오리·똥·떡볶이는 원본 0번을 그대로 유지하고, 쿼카만 둥근 귀·웃는 입·갈색 체형으로 새롭게 해석합니다.

원본 4종의 외형 승인과 발 연결·중복 동작을 고친 전체 72프레임의 승인은 별개입니다. 쿼카의 새 외형은 승인 전이며 전체 동작 시트는 아직 제작하지 않았습니다.

2. 움직임 비교

수정 후보 우선에서는 4종의 수정된 72프레임과 쿼카의 원본 18프레임을 구분해 표시합니다. 원본으로 바꾸면 같은 동작·번호의 수정 전 그림을 비교할 수 있습니다. 쿼카의 새 외형은 위 정지 그림으로만 확인합니다.

캐릭터 자료 불러오는 중

30 FPS로 갱신합니다. 걷기 2–5번은 각 0.16초, 이동은 앱의 22pt/s × (선택 배율 ÷ 2)입니다. 24px 원본은 앱에서 48pt이므로 2×를 기준으로 환산합니다. 이동 좌표는 정수 픽셀로 표시합니다. 반전은 검사자가 직접 선택하며 자동 방향 반전 정책을 제안하지 않습니다.

졸기 0.8초/장 · 잠 1.2초/장 · 던지기 0.1초/장 · 피격 0.11초/장. 던지기·피격은 한 번 재생하고 기본 자세로 돌아갑니다. 파란 선은 원본의 위에서 y=21 경계(아래쪽 3px 여백)입니다. 화면을 숨기면 재생을 멈춥니다. 이 검사는 실제 앱 실행 검증이 아닙니다.

3. 캐릭터 프레임 비교

캐릭터당 기본 10장 + 던지기·피격 8장. 번호는 각 시트의 0번부터 셉니다. 프레임을 누르면 위 검사 화면에서 정지 상태로 볼 수 있습니다. 파란 선은 발 기준선입니다.

4. 선택한 물건 5종 프레임 검토 대기

시바견 테니스공 · 오리 목욕용 고무 오리 · 똥 휴지 뭉치 · 떡볶이 어묵꼬치 · 쿼카 잎사귀입니다. 물방울과 풀 뭉치는 현재 선택에서 제외했습니다.

실제 16×16 후보를 정수 배율로 표시합니다. 물건당 회전 8장·충돌 4장으로 총 60프레임입니다. 물건 기획·콘셉트 그림의 승인이 최종 회전·충돌 연출 승인을 대신하지 않습니다. 고무 오리는 기존 자산을 참고하며 이번 캐릭터 연결은 출시 전 검토입니다.

검토용으로 각 프레임을 0.1초씩, 30 FPS 화면 갱신으로 반복합니다. 실제 앱의 회전·충돌 타이밍은 합성 단계에서 따로 검토합니다. 소리는 재생하지 않습니다.
