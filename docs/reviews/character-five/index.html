SIDEY / CHARACTER REVIEW

다섯 친구, 외형부터 확인하기

정지유 (@jungjiyu)의 원작과 수정 후보를 비교하는 로컬 검토 자료입니다. 현재 단계는 실제 외형 픽셀 검토·쿼카 물건 비교입니다.

원본을 직접 수정하는 외형 방향과 물건 4종의 기획이 선택되었습니다. 아래 실제 외형 후보·쿼카 물건은 검토 대기이며, 전체 동작·음원 승인은 별도입니다. 페이지 조작은 승인을 기록하지 않습니다.

외형 비교원본 움직임원본 90프레임물건 기획

1. 실제 외형 픽셀 비교 후보 검토 대기

승인된 방향에 따라 원본을 직접 수정한 24×24 PNG 후보입니다. 실제 원본·후보·각 실루엣을 같은 정수 6배로 표시합니다. 색과 표정, 귀·볼·몸통 차이를 확인해 주세요.

똥·떡볶이는 기본 0번의 원작 외형을 유지했습니다. 문제가 있는 다른 프레임의 발 연결과 동작은 전체 프레임 수정 단계에서 다룹니다.

참고: 승인된 외형 방향의 생성 콘셉트

참고 콘셉트 파일을 불러오지 못했습니다.

2. 원본 움직임 검사

아래 움직임과 전체 프레임은 수정 전 원본입니다. 외형 승인 후 전체 수정본을 별도로 검토합니다.

원본 불러오는 중

30 FPS로 갱신합니다. 걷기 2–5번은 각 0.16초, 이동은 앱의 22pt/s × (선택 배율 ÷ 2)입니다. 24px 원본은 앱에서 48pt이므로 2×를 기준으로 환산합니다. 이동 좌표는 정수 픽셀로 표시합니다. 반전은 검사자가 직접 선택하며 자동 방향 반전 정책을 제안하지 않습니다.

졸기 0.8초/장 · 잠 1.2초/장 · 던지기 0.1초/장 · 피격 0.11초/장. 던지기·피격은 한 번 재생하고 기본 자세로 돌아갑니다. 파란 선은 원본의 위에서 y=21 경계(아래쪽 3px 여백)입니다. 화면을 숨기면 재생을 멈춥니다. 이 검사는 실제 앱 실행 검증이 아닙니다.

3. 원본 90프레임

캐릭터당 기본 10장 + 던지기·피격 8장. 번호는 각 시트의 0번부터 셉니다. 프레임을 누르면 위 검사 화면에서 정지 상태로 볼 수 있습니다. 파란 선은 발 기준선입니다.

4. 애착 물건 기획 4종 선택 · 쿼카 비교 대기

시바견은 테니스공, 오리는 물방울, 똥은 휴지 뭉치, 떡볶이는 어묵꼬치로 기획이 선택되었습니다. 쿼카는 잎사귀와 풀 뭉치 두 안을 비교한 뒤 선택합니다.

모두 캐릭터와 별도 판매할 물건입니다. 아래 그림은 동일한 생성 콘셉트 보드의 해당 부분을 확대해 보여 주며, 최종 픽셀·회전·충돌 프레임 승인을 뜻하지 않습니다.
